### Part 2 — the knowledge pipeline (SPEC-KNW-001)

Spec written and approved before code. Architecture: **A** raw (ingestion,
immutable) → **B** processed (`data/processed/`) → **C** candidate knowledge
+ questions (`data/knowledge/candidates|questions/`, UNVERIFIED) → concepts
(`data/knowledge/concepts/`, one concept, many supporting sources) →
verification queue (append-only) — trusted `knowledge/` untouched.

- **Processor** — null-safe assembly (caption → slide OCR in order →
  transcript → on-screen); empty content → `skipped_reason: "no_text"`, zero
  model calls; OCR/transcription are `Protocol` interfaces for later.
- **Extraction schema** — strict validation with field-path errors; subjects
  and knowledge types enum-enforced (new subject = data edit in taxonomy);
  `STATED_BY_SOURCE` answers must exist and be among stated options;
  `NOT_STATED` answers must be null; NOT_RELEVANT must not smuggle items.
- **Prompt** — `knowledge-extraction-v1`, versioned module; instructs atomic
  extraction (the 26-Nov-1949 / 26-Jan-1950 example is built in), uncertainty
  marking, never-invent, questions-separately, source-claims-not-truth,
  strict JSON.
- **Routing** — new `KNOWLEDGE_EXTRACTION` role (glm, anthropic fallback) +
  independence pair to `VERIFICATION`, validated by the existing validator.
  Client is env-keyed (`GLM_API_KEY`/`GLM_BASE_URL`); no key in any tracked
  file; live call raises `MissingKeyError` honestly when unset.
- **Candidates/questions** — deterministic ids over
  (source, content, prompt, index, text); full provenance block on every
  record; `verification_status` UNVERIFIED only.
- **Scoring** — `docs/relevance_scale.md` v1, deterministic rules; syllabus
  mapping is data citing verified `OFF-SYL` node ids
  (`config/subject_syllabus_map.json`); `pyq_similarity` null (no
  denominator); `constable_relevance` carries PROVISIONAL basis
  (Constable notification not retrieved).
- **Dedup/corroboration** — concept key over stopword-stripped,
  curated-synonym-canonicalized tokens + knowledge type
  (`config/dedup_synonyms.json`; "not" never dropped); append-only supporting
  sources; `corroboration_is_not_verification: true` on every concept.
- **Verification queue** — records required verifier provider (resolved
  AUTO_NOT_AUTHOR, differs from author); no verify method exists anywhere in
  the pipeline (structurally asserted by test).
- **Batch** — checkpoint after every item; resume skips dispositioned items
  and retries failed ones (failed items are removed from `failed` on
  success); prompt-version change re-scopes the checkpoint; cost controls:
  empty, already-processed, and within-run duplicate text never reach the
  model.

Committed as `7a15b77`.
